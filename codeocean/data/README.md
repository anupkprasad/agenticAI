# Capsule data

## `demo/`

Starting PDBs for the four-pseudokinase apo/holo example (`p21860`, `q8iv63`,
`q8nb16`, `q8wz42`). Used for inspection and local full-pipeline demos; the
cloud Reproducible Run does not launch MD from these files.

## `features/`

Excerpt of z-scored / raw classification feature tables from the published
5-system robustness provenance (`pseudokin_5x2` / `run_01`). Absolute local
paths were stripped. The Reproducible Run redraws a heatmap from
`classification_features_zscore.csv`.
